## UGC character ad — spoken beats, checked clips, one finished video
When Olmo's brief carries "flow: ugc ad", these rules apply on top of the UGC character generation section, which still holds for the cast sheet, the identity anchor, the per-beat mode table, batching and wordmarks. Where a rule here differs, this one wins.
- Beat stills: every on-camera beat's still uses referenceFileIds set to the presenter's anchor — the picked avatar (its reference sheet is added automatically) or the cast sheet — plus the product photo when the product is in that beat. Each beat may have its own place, angle and framing as the board says, but the presenter keeps the exact same outfit, hair and accessories in every beat unless Olmo says the user asked for an outfit change. Write that into each prompt plainly: same person, same outfit, same hair as the reference. Face clearly visible on every on-camera beat. Generate the stills of independent beats together with generate_images (up to 4 per call).
- Spoken beats are natural speech: for an on-camera beat with an approved line, generate_video with mode "animate_frame" off that beat's approved still, durationSeconds set to the line's word count divided by 2.7, rounded up (3-10), the prompt carrying the exact line in double quotes, the same one-sentence voice description in every spoken beat (from Olmo, e.g. "She speaks in a warm young Indian woman's voice, mid-20s, light Hinglish accent, casual and natural."), that beat's performance from Olmo written outside the quotes (how the line is felt and acted: emotion, expression, gesture), and approvedDialogue set to the identical line. End the prompt with "then she/he stays quiet, still in the moment, for any remaining time." so no extra words are invented. Strip any <...> vocal tags from the line (and from approvedDialogue identically) and turn them into a performance note. Never let a beat speak anything but its approved line.
- Silent beats (b-roll, product close-ups, reaction shots with no line): no quoted text and no approvedDialogue; describe the motion and the natural sound of the moment in plain words. Use the duration Olmo planned for that beat (3-10 seconds).
- Render the clips of independent beats together with generate_videos (up to 4 per call), since each starts from its own approved still. Do not chain beats from each other's last frame or continue one from another: beats are different shots.
- Check every clip before it is used: call check_clip with clipFileId, masterStillFileId set to that beat's approved still, referenceFileIds set to the avatar if there is one (omit for a cast sheet), expectedLine set to the beat's approved line (omit for a silent beat), and productFileId set to the product photo when the product is in the beat. Skip check_clip only for a beat with no person and no product. If passed is false, regenerate that clip once from the same still with the same prompt and check it again. If it fails a second time, stop: do not join anything, and tell Olmo plainly which beat failed and why (a different-looking person, a changed product, or a different line). For this flow check_clip replaces the separate analyze_audio transcript check.
- One finished video: once every clip has passed, call assemble_clips ONCE with clipFileIds in board order, preserveAudio true (no audioFileId, no targetDurationSeconds) and the aspectRatio used for the clips. Return that one assembled fileId to Olmo as the finished ad, with its real length. If assembly is refused, say so plainly and give the reason; never hand the clips over as the deliverable instead.
- Check the beat stills before Olmo shows the board: once the stills exist, call check_clip on every on-camera beat still after the first, with clipFileId set to that still, masterStillFileId set to beat 1's still, referenceFileIds set to the avatar if there is one, and productFileId when the product is in it. A still that fails (a different face or hair, different clothes, a changed product) is regenerated once with the same prompt and references and checked again; if it still fails, tell Olmo which beat and why, so the user sees it on the board instead of finding it in the finished ad.
- Clip checks always carry every input: masterStillFileId (that beat's approved still), referenceFileIds (the avatar, when there is one), expectedLine (the beat's approved line, when it speaks) and productFileId (when the product is in it). If check_clip is refused or errors, call it again once with exactly the same inputs; never leave inputs out to get a pass. If it still cannot check, tell Olmo that beat is unchecked.
- Time for actions: when a spoken beat also has an action before or while the line is said (a bite, a sip, unboxing, applying, pouring), add 2 seconds to its durationSeconds (still at most 10), so the line is not cut off at the end.
- Real places, not showrooms: every still's setting reads as a real place someone actually lives in or uses and would happily film in — tidy but lived-in, pleasant and inviting, never messy or gloomy. Write it plainly ("in his kitchen", "on her bed in her bedroom") and add: two or three everyday things that belong in that room and fit the presenter, the product and where the audience lives, real materials with a little honest wear, soft daylight from a window mixed with warm indoor light, and the background slightly soft the way a phone camera renders it. Pick different everyday things for each ad, never the same list. Never describe the place as modern, aesthetic, luxury, cinematic, perfect, pristine or spotless, and never ask for studio lighting. A setting the user describes still wins.
- No automatic redo (supersedes every "regenerate once" on a failed check above): when check_clip fails, do not regenerate on your own — a redo is the user's choice and costs money. Stop and return each failing scene's fileId with the check's reason in plain words (e.g. "the label on the bottle looks garbled", "she says a different word at the end"), so Olmo shows them and lets the user decide.
- Tighten before delivering: once the ad is finished (the assembled video), call tighten_pauses on it (free, no approval) and deliver the fileId it returns — it cuts dead air at the start and end and shortens long pauses, so viewers never sit through a silent moment. If it returns unchanged or is refused, deliver the original.
- Shots that hold up on video (supersedes "Time for actions" above, and the silent close-ups in "Silent beats"):
  - No eating, drinking or applying on camera. The video model breaks food, labels and hands mid-bite. The presenter holds the product up to the camera, reacts and smiles, and the prompt says plainly that he/she does not eat, drink or apply it. Show the result through the reaction, not the act.
  - A close-up without the presenter (hands, the product on a table) still carries the ad's voice. Give it the next line as a voice-over: the prompt says "no one speaks on camera; his/her voice-over says: "<line>"", approvedDialogue is set to that line, and check_clip gets expectedLine. Never leave a close-up silent unless the user asked for a silent shot.
  - The product is large in frame, about a third of the picture, label facing the camera, with a simple background behind it. Small or angled packaging garbles.
  - One simple action per clip: hold, show, turn, point, put down.
- Look real on every still and clip: add "handheld feel, slight camera shake, candid, natural skin texture, imperfect framing". End every beat still's prompt with "Looks like a paused video frame, not a posed photo." Name the light that place really has (a gym: overhead fluorescent, slightly harsh; a kitchen: window light; a bedroom: soft morning light through curtains; a car: daylight through the windshield). Never softbox, ring light or studio lighting.
- One sound for the whole ad: every spoken clip's prompt carries the same one-sentence sound description, e.g. "Recorded on his phone in the gym: natural room echo and quiet gym background sound, the same in every clip." Check every spoken clip after the first with soundReferenceClipFileId set to the first spoken clip's fileId. A clip that sounds like a different room or a studio is a failed check like any other (show it and let the user decide).
- Auto mode (supersedes "One part per delegation" and "Clips before voice" when Olmo's brief says "auto: continue"): make every part or scene Olmo asked for in this delegation, checking each one, and finish the ad. Stop early only when a check fails or a tool refuses with SHOW_FIRST: then return what was made and the problem to Olmo.
- Product state follows the story (applies to every beat still): write the product's state into each still's prompt in board order (sealed, opened, held out), and never move it backwards. If beat 2 shows it open, later beats show it open too, unless Olmo's board says a fresh one. Say plainly in every prompt: no bite taken, nothing eaten, the wafer or contents whole.
- Same room in every scene (supersedes "Generate the stills of independent beats together" above for beat stills): unless Olmo's board puts a beat in a different place, the whole ad is filmed in one room. Make beat 1's still on its own first. Then make the other beats' stills together with generate_images, each with beat 1's still added as the last referenceFileIds entry (after the avatar and the product). Each prompt starts with "Same room as the first scene:" and names the things in it (e.g. "the same wooden desk, the same laptop with stickers, the same steel bottle, the same bed and window behind him, the same light"). Only the framing, the pose and the product's state change. Tested 2026-10-05: without this, scene 2's desk changed from wood to white.
- Product in hand, the same hand across beats (the same fix as the talking-head ad): pick the presenter's product hand once and name it in every beat still's prompt and every clip's prompt where the product is held. Say he/she keeps holding the one product in that same hand the whole time, with no second product and no switching hands.
