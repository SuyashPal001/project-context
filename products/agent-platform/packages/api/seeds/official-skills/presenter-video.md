## Presenter video — spokesperson/announcement ad with on-screen graphics, always in both 16:9 and 9:16
This contract applies when the user wants a presenter announcing something — a program, a product launch, a policy update, a service — WITH on-screen graphics (title cards, info cards, captions, a screen walkthrough, a compare card, a follow card), delivered in both 16:9 and 9:16 at once. If the user wants a plain presenter reading a script to camera with no graphics overlay, use the Talking-head ad contract instead. If the user wants a multi-beat storyboard ad with distinct shots, use the UGC character ad contract instead. Signals: "presenter video", "announcement video", "spokesperson with graphics", "make a video announcing X", a reference like the source video described in the skill's own origin (a presenter with a flag/brand backdrop, caption pills, a screen walkthrough with a presenter picture-in-picture, a follow card).
Every agent-director call in this flow includes the line "flow: presenter video", so Director loads this skill's rules.
1. Intake: get what is being announced (the plain facts: what, who it's for, any dates/eligibility), a presenter look brief (appearance, setting, wardrobe, or a picked avatar), the script or enough to write one, and whether any screens need to be shown (a real site to walk through, or illustrative cards only). Ask only what cannot be inferred.
2. Tell the user plainly, before delegating: this flow produces TWO finished videos (16:9 and 9:16) from one script and cast, with roughly 10-14 separate cost confirmations across casting, both master stills, the per-part clips for both aspect ratios, graphics, capture (if any), and the music mix — there is no single approval that covers the whole flow.
3. Casting: apply the TVC character creator contract's casting quality (a strikingly attractive, camera-ready lead actor, never a plain stock-HR face) even when building a fresh presenter rather than a saved avatar. If the user picks a saved avatar, use it as-is.
4. Two master stills, not one: delegate to agent-director to build the 16:9 master (waist-up, presenter in the left third, right third left clear for graphics, eyes on the upper third with headroom, background in the announcement's own style) and, once that is approved, the matching 9:16 master (same person, outfit and setting, presenter lower in frame so the top and bottom stay clear for 9:16 safe zones — Reels-style, roughly the top 220px and bottom 380px of a 1080x1920 frame). Show each for approval before building the next; every change before approval is an edit of that master, never a fresh generation. Once approved, write both into working memory's Locked Reference Artifact IDs as "Master still 16:9: <fileId>" and "Master still 9:16: <fileId>", and restate both in every later delegation.
5. Script split into parts of at most 10 seconds on sentence boundaries. For each part, write one gesture direction tied to that line (a namaste open or close, a palm toward the free side when a graphic will appear there, a hand on the chest for reassurance, both hands out for an either/or choice, counting fingers for a numbered list) — gestures should run early in the line unless tied to one exact word ("only on the word 'open' does she raise a second finger"). Show the split and gestures to the user for approval before delegating.
6. Delegate ONE part at a time, for EACH aspect ratio, from its own locked master still — this flow always builds both 16:9 and 9:16 end to end, never one first and the other "later". After a part is approved in both aspect ratios, move to the next part. For a gesture-heavy part, tell Director to make two takes and keep whichever's gesture timing matches the speech timing, measured not eyeballed.
7. Once every part is approved in both aspect ratios: delegate to assemble each aspect ratio's parts into its own silent presenter cut (never mix 16:9 and 9:16 clips together).
8. Graphics: for each aspect ratio's assembled cut, decide the graphic beats from the script's own phrase timings (from the trim pass) — a title card at the open, info cards for key facts, phrase captions with the key word highlighted, a follow card at the close, a corner mark reading "Concept sample" unless the user gives real branding. If any beat needs a real screen (a site to apply on, a dashboard), delegate a capture_webpage call for a public page, or ask the user for a screen recording/their own login session for anything behind auth — never ask for or store credentials. Delegate render_graphics once per aspect ratio with that aspect ratio's own beat list and coordinates (16:9 layouts are not simply cropped 9:16 layouts — Director lays each out for its own frame).
9. Mix: delegate mix_music_bed with bedLevel "subtle" (never "standard" — this is a speech-led video) on each aspect ratio's graphics pass, after a subtle music bed has been generated or picked.
10. Delivery: present both finished videos (16:9 and 9:16) together as the one announcement, each playable, in the SAME reply — never deliver one aspect ratio and promise the other "later" unless the user explicitly asked for only one.
11. Real documents: if the announcement needs a real-looking ID card, booklet or certificate, apply dummy values and a visible SPECIMEN mark. Any official emblem or protected mark (a national emblem, a government seal) is used only when the client is the government body itself that owns it — say so plainly to the user before using one, and refuse otherwise.
12. Auto mode: never ask about cost, and do not stop to ask "good to continue?" after a step that came out well — show it in one line and carry on. Stop and ask only when a check fails or something only the user can give is missing (a screen to capture, a choice of style). In Ask mode, show the first part in both aspect ratios before continuing to the rest, same as Talking-head's own first-one-first rule.
13. Script writing: same as Talking-head — write the way a real person speaks, not ad copy, with numbers and symbols spelled out as spoken words, sized at about 2.7 words per second per part.
14. Settings: describe the location plainly as a real place that fits the announcement ("a formal consular office", "a tidy home studio"), never as modern, aesthetic, luxury, bright, cinematic or perfect.
