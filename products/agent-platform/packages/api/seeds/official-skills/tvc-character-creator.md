## TVC character creator — a polished commercial lead actor, made in chat
When the user wants a new reusable lead actor for TV-commercial style ads — polished, premium, styled like a brand shoot — rather than a candid UGC creator (use the Avatar creator skill for that) or an animated character (use the Animated character creator skill):
- Infer everything you can instead of asking: what the actor is for (the product, its audience) from this conversation, the brief, the user's products and working memory; then the look, wardrobe and set that fit it. Honor exactly any gender, age, ethnicity or look the user stated or the product's stated audience states. Never infer gender, age or ethnicity from a name. Never infer ethnicity from a market or region.
- Never recreate a real celebrity, actor or public figure. If the user names one or attaches a photo of one, make an original person with a similar vibe and styling, and say plainly why in one line.
- Ask at most ONE ask_clarifying_questions card, and only for what you cannot infer. The card holds at most four single-select questions, each with options and allowFreeText true — never a bare free-text question the user has to answer from scratch:
  1. "What's this actor for?" — options: any product named or attached in this conversation first, then common categories such as "Jewellery & fashion", "Beauty & skincare", "Home & appliances", "Food & beverages".
  2. "Who should we cast?" — options "Women", "Men", "A mix — women and men". Recommend the one the product's audience points to (a women's jewellery or beauty product → "Women"); when nothing points either way, recommend "A mix — women and men". Skip this question only when the user or the product's stated audience already gives the gender.
  3. "What vibe should they have?" — options "Aspirational & premium (Recommended)", "Warm & family", "Bold & glamorous", "Trusted & professional".
  4. "Who should they look like?" — options "A mix — 4 different looks (Recommended)" and "Indian". Free text covers any other look.
  Put the option you recommend first, add " (Recommended)" to its label, and say why in one short line in its rationale. Skip the whole card only when the brief already says what the actor is for and the look. Otherwise ask only the questions still open. Never ask separately about age. Pass the cast answer as the gender: "woman", "man" or "any" for a mix.
- Age range: exactly what the user or the product's stated audience gives; otherwise 22–45. Never narrow it yourself.
- Framing: full body when the outfit is part of what the actor sells — fashion, apparel, jewellery, or the user asks for full body; otherwise from mid-thigh up. Say the framing in the plan's "Who:" line and pass it to agent-director as "framing: full body" or "framing: mid-thigh up".
- The plan names the four in one plain "Who:" line before the cost, for example "Who: four original lead actors, women aged 22–45, each a different look, in styled premium wardrobe on commercial sets." — say "men" or "women and men" instead to match the cast answer. Say they are vertical 3:4 stills from mid-thigh up, or full body when the framing is full body. Then say that after the pick you will refine the face so it reads like a real camera, and make a full character reference sheet — a continuity bible with a turnaround, face views, eight expressions, six poses, costume details and a colour palette — which keeps the actor identical across every later ad.
- Cost: follow the credit-spending confirmation rule — the plan is 4 variations, then after the pick 1 face refinement and 1 character reference sheet. The approval cards carry the exact cost.
- Record the brief (what it's for, vibe, look, age range) under Key Decisions only — never in Brand Context or User Preferences.
- Delegate by calling the agent-director tool — never by writing a message to it in your reply; the user must never see an "@agent-director" request. In that tool call's message, write "style: tvc", what it's for, the vibe, the look, the gender (or "any") and the age range exactly as in the plan, and aspectRatio "3:4".
- Never call your own generate_image for this, not even one variation at a time. Always ask agent-director for all 4 variations in ONE generate_images batch, so the user approves once and the four render together.
- Then call ask_clarifying_questions with one single-select question, "Which one should become your TVC actor?", options Option 1 to Option 4 in the order generated, plus {label: "None of these — change something"}, allowFreeText true. Set each of the four options' imageFileId to that variation's own fileId (Option 1 = the first variation's fileId, Option 2 the second, and so on) — never set imageFileId on the "None of these" option.
- If the user picks none of these, get the change they want (a free-text follow-up if they gave none), then treat it as a new plan: fresh cost estimate, fresh approval, re-delegate for 4 new variations. Never regenerate on a guessed change.
- Once they pick, map the chosen option to that variation's fileId and pass that fileId explicitly to agent-director, with "style: tvc" and the brief — Director cannot see your working memory. Delegate to agent-director to refine the face of that still, generate the character reference sheet from the refined still, and save it with save_as_avatar. Show the reference sheet in your reply and say it is what keeps the actor the same in later ads.
- Only say the actor is saved when Director reports a save_as_avatar result with saved true, and use only the name that result returns — never make up a name. If the sheet or the save failed, tell the user plainly that the actor was NOT saved and why in one line, show only the still they picked, and offer to try again. Never tell the user it is in Drive or the picker unless the save succeeded.
- Then tell the user the actor's name and that it is in Drive › Avatars and under "Yours" in the avatar picker. If the result says referenceSheet is false, say plainly the reference sheet didn't save, so later ads may drift, but the actor itself is saved and usable.
