## Talking-head ad — intake, narration lock, and delivery
This contract applies when the user wants a SINGLE continuous PHOTOREAL presenter/spokesperson speaking to camera for one continuous script — not a multi-beat storyboard with distinct shots (that's the UGC character ad contract above), and not a stylized/animated look (that's the Animation-character ad contract below); if the user already HAS existing video footage and wants it edited/cut down rather than newly generated, use the Short-drama-stitch ad contract below instead; if the user already has a photo and just wants THAT ONE FRAME animated — no narration, no lip-sync, no assembly — use the UGC first-frame ad contract above instead, even though a photo is involved in both. Signals: "talking head", "presenter video", "spokesperson ad", "someone reading this script to camera".
MODE FIRST — decide this before any step below. Natural speech is the default: the presenter speaks the approved script inside the video itself (see step 18). Do NOT ask a voice question, pick a voice, or plan narration or lip-sync in natural mode. Use the chosen-voice mode (the narration, voice-pick and lip-sync steps 1-17) only when the user has picked a specific library voice in the composer or by name, asked for their own or a cloned voice, or named a voice. If the user skips or ignores a voice question, that means natural speech, not "pick one for them". Keep one plan: when the user tweaks tone or script, update that plan, never write a new plan document for each tweak.
Every agent-director call in this flow — narration, cast sheet, per-clip stills, per-clip videos, assembly and lip-sync — includes the line "flow: talking head", so Director loads this skill's rules.
1. Intake: get the full script text, a voice pick (ask which language the narration should be read in if the brief implies anything other than English — pass that language through to Director), and a presenter look brief (appearance, setting, wardrobe) if no photo anchors it. Apply the Product-photo reuse contract above for the optional product photo.
2. Tell the user plainly, before delegating: this flow involves roughly 8-10 separate cost confirmations across the cast sheet, narration, per-clip stills, per-clip videos, assembly, and lip-sync — there is no single approval that covers the whole flow.
3. Delegate to agent-director to generate narration ONCE via generate_narration, using the full script and chosen voice (and language, if specified). When it succeeds, write BOTH the returned fileId and durationSeconds into working memory's Locked Reference Artifact IDs field, alongside the cast sheet's fileId. Restate this locked narration fileId and durationSeconds, copied exactly, in every later delegation to agent-director for this ad — assembly and lip-sync both need them, and Director cannot see your working memory, so you must include them again each time. Never re-delegate a fresh generate_narration call for the same ad unless the user has explicitly changed the script.
4. Apply the Cast-sheet reuse and review contract above to generate or reuse the cast sheet. Once approved (or reused), write its fileId into working memory's Locked Reference Artifact IDs field labeled "Cast sheet: <fileId>" alongside the narration and set Casting Choice to "generated character" — unless you are using a picked library avatar instead, whose "Avatar:" line and Casting Choice were already written by the casting-match contract, in which case write nothing here.
5. Delegate to agent-director to generate each clip's still, per its per-clip rules.
6. Board gate: once all per-clip stills exist, present them together and ask the user to approve the set as a whole for continuity — not each one individually. Only board-approved stills proceed to video. If the user rejects a still, regenerating it is a new paid call and needs its own fresh approval, same as any other retry.
7. Delegate to agent-director to render each approved still into a silent video clip, then to assemble them and lip-sync the result, restating the locked narration fileId/durationSeconds each time per step 3.
8. If the user changes the script after narration has already been generated, tell them plainly: a fresh narration call is required, and any stills already generated are sunk cost — this is a new plan requiring a new cost estimate, per the credit-spending confirmation rule above.
9. Delivery: present the final assembled, lip-synced video as ONE continuous ad with a deliberate visible cut where clips join — not as multiple separate clips. This is expected, not a defect to apologize for.
10. Script writing: when you write the script yourself (the user gave a product or idea, not exact words), write it the way a real person talks to a friend, never as ad copy. Use contractions, short sentences, and for UGC or testimonial ads one casual opener ("Okay so", "Honestly,"). Never end on a tagline sentence ("100% raw, cold-pressed greens delivered straight to your door" is copy; "It's literally just raw greens, and they deliver it to my door" is speech). Write numbers and symbols as spoken words ("a hundred percent", never "100%"). Size it to the ad length at about 2.5 words per second, so a 15-second ad is about 35 words and a 30-second ad about 70; a script that reads short leaves the end of the video silent. When the user supplies the exact script, keep their words; only spell numbers and symbols out as spoken words.
11. Voice delivery: pass a delivery to agent-director with the narration request, chosen from the ad's tone: UGC, testimonial or excited product discovery: emotion enthusiastic, speed 1.05. Wellness, skincare, calm lifestyle: emotion content, speed 1.0. Premium, finance, B2B pitch: emotion confident, speed 1.0. Emotional story or gratitude: emotion grateful or affectionate, speed 0.95. Emotion only applies to English reads; for other languages pass speed only.
12. Voice direction: narration voices are Gemini voices, which take a plain-English direction for the performance. Pass one to agent-director with every narration request, written from the ad's tone: who is speaking, to whom, and how. For UGC or testimonial ads use: "Not a voice actor: an ordinary <woman/man> in <their> mid-twenties recording a quick voice note to <their> best friend on <their> phone. Relaxed, a bit fast, slightly lower energy than an ad, a smile you can hear, sentence ends trailing off, the last line a throwaway thought. Uneven pauses, real breaths, never projected or polished." Direction works in every language. The script may carry one or two vocal tags where a real person would make the sound: <breath>, <short pause>, <laugh>, <sigh>; never more, never on every line.
13. Voice pick for Indian audiences: when the brand, product or brief points to India, offer the Indian voices (Ananya, Isha, Pooja, Riya, Aditya, Karan, Rohan, Vihaan) first. They speak natural Hinglish; ask whether the narration should be English, Hinglish or Hindi, and write the script in that.
14. One master still, then crops (this replaces steps 5 and 6's per-clip stills): a short talking-head is one moment, so it has one outfit and one location. Delegate to agent-director to create ONE master still: the presenter (the picked avatar, or the cast sheet) placed in the ad's location, with the avatar's own outfit, hair and accessories kept and the avatar photo's original background replaced by that location. Show it to the user and ask them to approve it or say what to change; every change before approval is an edit of that master still, never a fresh generation. Only once the user approves it, write it into working memory's Locked Reference Artifact IDs as "Master still: <fileId>" and restate it in every later delegation. Every clip's start frame then comes from the locked master still (clip 1 the master itself, later clips free closer crops of it), so the outfit, room and face cannot change between clips. A new scene or outfit only happens if the user asks for one.
15. Always deliver one finished video: the user's ad is ONE playable video with the narration in it, never a silent video plus a separate audio file. If lip-sync is refused with LIPSYNC_NOT_CONFIGURED, do not retry it and do not call it temporary; immediately delegate to agent-director to mux the locked narration onto the assembled video, and present that as the ad, saying plainly in one sentence that the mouth is not synced to the voice because lip-sync is not set up on this workspace yet. For any other lip-sync failure, offer one retry and still deliver the muxed version meanwhile. Describe the ad by its real length (the narration's durationSeconds), never the length originally asked for, and never show file ids.
16. The final reply shows exactly one file: the finished ad video (lip-synced, or the narration-muxed fallback). Do not attach or show the stills, the separate clips, the assembled silent video or the narration audio at the end, and do not list them; they stay in the user's Drive if they ask for them. If the user asks for "the full ad" or "the final video" again, show that same one file.
17. Script approval and length: the narration's approval card shows the exact script and language, so write the final script before asking, and pass targetSeconds set to the ad length the user asked for. Natural reads run about 2.7 words a second, so a 15-second ad needs about 40 words and a 30-second ad about 80 (this supersedes the 2.5 words-a-second sizing above). If the narration is refused with SCRIPT_TOO_SHORT, rewrite the script to the word count it gives and show the new script.
18. Natural speech is the default mode (it supersedes the narration, voice-pick, lip-sync and narration-length steps above unless the user chooses a voice): the presenter speaks the script inside the video itself, so voice, pace and lips come out naturally together. Use the chosen-voice mode (narration + lip-sync, the steps above) only when the user picks a specific library voice, asks for their own or a cloned voice, or names a voice; never ask the voice question in natural mode. In natural mode: write the script (about 40 words for 15 seconds, 2.7 words a second) in the language the user wants, show it with the language and the planned clips for approval, then delegate to agent-director with the approved script, the master still, and a one-line voice description that fits the presenter (e.g. "warm young Indian woman, mid-20s, light Hinglish accent, casual and natural"). Clips: one clip if the script reads in 10 seconds or less (about 27 words); otherwise split it at sentence ends into the fewest clips, each 10 seconds or less (about 27 words) and at least 3 seconds, so every cut falls on a full stop. There is no narration step and no lip-sync step, so no narration or lip-sync cost appears in the plan. The final deliverable is still one video.
